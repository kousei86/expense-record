Webブラウザ上で支出品目と金額を登録し、一覧と合計金額を表示します。  
支出記録は、WebブラウザのLocal storageに「expenseData」という名前で自動保存されます。  
そのため、同じブラウザで次回アクセスした際、保存したデータで再開されます。  
<a href="https://kousei86.github.io/expense-record/"  target="_blank" rel="noopener noreferrer">https://kousei86.github.io/expense-record/</a>

支出記録がサーバーに送信されることはありません。
また、別の端末やブラウザとは共有されません。  
気になるようでしたら、Local storageにあるデータを消去してください。
